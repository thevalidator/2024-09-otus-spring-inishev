# Краткая инструкция по запуску

- добавить RSA ключи
- заполнить значения параметров в application.properties
- применить [скрипт](data/init.sql) к БД 

После этого можно запускать проект и создавать пользователей. 
Роль администратора назначается вручную путем sql запроса.

API документация доступна после запуска по адресу: http://localhost:8080/api-docs

## Краткое описание

Приложение для проведения автомобильных соревнований в формате time-attack. 
Участники регистрируются на соревнования указывая свои данные, автомобиль и зачетный класс (различаются по мощности и типу привода) в котором будут выступать.
Само соревнование состоит из одной и более сессий. Сессии могут быть двух типов: практические и зачетные. 
В практических сессиях, как правило, нет ограничений на максимально разрешенное количество кругов, которое может проехать экипаж. 
Участники тренируются, и результаты практических сессий никак не влияют на итоговые результаты соревнований. 
В зачетных сессиях количество кругов практически всегда ограничено одним кругом, тк смысл time-attack соревнований - показать лучшее время круга с одной попытки. Зачетных сессий может быть несколько. Итоговый результат складывается сложением времен всех зачетных сессий. Первое место занимает экипаж, показавший самое быстрое время. 
Если экипаж не совершил заезд в зачетной сессии, ему назначается штрафное время, равное самому медленному результату сессии плюс 10 секунд.
